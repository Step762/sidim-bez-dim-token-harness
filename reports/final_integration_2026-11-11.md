## Подключение

Использованы готовые `coding_static.py` и ограниченный AST-verifier Ильи.
Решатель выводит правку из исходника и литеральных unittest-проверок,
без ручного контракта, import/eval/exec или запуска Python задачи.
Поддерживается только проверенное подмножество форм; неоднозначность,
посторонние файлы, неподдерживаемые конструкции и подмена файлов дают отказ.
Правка сохраняется в workspace; `DONE` публикуется рядом с task.json через
проверенный callback. Проверки из задачи сохраняются неизменными.

Для официальной команды с одним `--tasks-dir` CLI включает этот статический
маршрут по умолчанию. `--disable-static-coding` отключает его. Существующий
`--static-coding` сохранён; `--trusted-code` — отдельный взаимоисключающий
режим для явно доверенных копий. Произвольный Python автоматически не запускается.
Низкоуровневый `run_tasks` сохраняет прежний default, чтобы controlled baseline
без Coding оставался воспроизводимым.

Math/Search/Data, LLM gateway/fallback, BudgetManager не изменены.
Graph/MathIR/Compiler и диагностический LIVE не активированы автоматически.
